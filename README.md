# iOS Camera Studio

بص هنعمل تطبيق عباره عن كاميرا فقط بتصميم ios 27.5 مع ازرار تنقل للكاميرا بين أوضاع الكاميرا ( لن نضيف فيديو حاليا ) 

بعد التقاط صوره سترسل الي gbt 2.5 مع هاذا البرومبت Clean up image and add Bokeh effect with natural tone and make it from iPhone 18 pro max

ثم ستعود الصوره الي المستخدم مره اخري في الجالري

سنضيف زر تعديل في الازرار التي بالاسفل 

سيفتح اختيار الصوره ثم سيفتح عدة فلاتر للاختيار منها سنضيف الفلاتر لاحقا وكلها ستكون بالذكاء الاصطناعي وايضا سنضيف قص وتعديل للصور مع استوديو كامل طبيعي مثل أي هاتف لاكنه كله مع تصميم ios 27.5 نظيف مع آشتراك شهري وسيكون هناك تجربتين فقط كل يوم لاكن لكل تجربه يجب مشاهدة اعلان


الصور من https://api.fastrouter.ai/api/v1
